كيف تشرح معمارية المنظومة في 3 دقائق؟ (Executive Pitch)

بطاقات سريعة مُعدة خصيصاً للمقابلات التقنية، الاجتماعات الإدارية، وعرض المشروع على المطورين والشركاء.

1. هيكلية المستودع الموحد (Monorepo)

فصل كامل مع تناغم تام

النظام مبني كمستودع موحد (Monorepo) مدار بواسطة pnpm، حيث يقبع تطبيق الواجهة في apps/web والخادم في apps/api، مع اشتراك في المعايير ومكتبات التحقق، مما يسمح بنشر وتطوير واختبار كل طرف باستقلالية أو بتزامن تام.

"نستخدم pnpm Workspaces لفصل الواجهة والخادم مع مشاركة الأنواع والتبعيات بسهولة."
2. معمارية الواجهة (Modern Client)

سرعة فائقة وتجربة تفاعلية

الواجهة مبنية بـ React 19 و Vite مع موجه المسارات السريع Wouter وإدارة الحالة والـ Cache عبر TanStack React Query، ومكتبة مكونات فاخرة مستندة إلى Radix UI و Tailwind CSS v4.

"لا توجد عمليات إعادة تحميل كاملة، فجميع الطلبات تتم عبر خدمات موحدة ومحمية برموز JWT."
3. تصميم الخادم والوحدات (Modular Backend)

طبقات مفصولة ومحكمة الحماية

الخادم يتبع نمط Modular Layered Architecture: كل مجال وظيفي من الـ 14 مجالاً ينقسم إلى 4 ملفات: routes (المسارات والتصاريح)، validation (التحقق بـ Zod)، controller (استقبال وإرجاع الردود)، و service (منطق العمل وقاعدة البيانات).

"كل طلب يمر بصمام أمان يبدأ بمحدد المعدل، فالمصادقة، ثم فحص Zod، وصولاً لمنطق الخدمة."
4. محرك البيانات المزدوج (Dual Storage Engine)

سرعة الصفر وفقدان الصفر

تجمع المنصة بعبقرية بين سرعة SQLite في وضع WAL والذاكرة للقراءة والكتابة في أقل من جزء من الثانية، مع محرك مزامنة سحابي تلقائي يرسل لقطات مشفرة فورية لقاعدة بيانات PostgreSQL السحابية (Neon/Supabase) لضمان بقاء البيانات عند نوم الحاوية المجانية على Render.

"سرعة المعالجة اللحظية من الذاكرة المحلية، مع أمان دائم عبر التخزين السحابي البعيد."

مصفوفة إعدادات المستودع والأتمتة (Monorepo & DevOps Matrix)

الملفات المشتركة، سكربتات النسخ الاحتياطي التلقائي، وملفات النشر بالحاويات.

الملف / الأداة الموقع الوظيفة والمسؤولية التقنية الطبقة المعمارية
pnpm-workspace.yaml Root تعريف فضاءات العمل المنفصلة (apps/* و scripts) وكتالوج التبعيات الموحد لمنع تضارب الإصدارات. Monorepo Engine
apps/api/server.mjs Backend محرك تشغيل الإنتاج عالي السرعة، يدير SQLite في الذاكرة ومزامنة PostgreSQL السحابية والنسخ المجدولة واستضافة الواجهة المبنية. Core Production Engine
scripts/backup-scheduler.mjs Scripts خدمة خلفية (Cron Daemon) تشغل النسخ الاحتياطي السحابي المزدوج يومياً في 03:00 و 15:00 UTC مع التحقق من التطابق. Automated DevOps
scripts/sync-and-verify-backup.mjs Scripts فحص سلامة وتطابق السجلات والبيانات بين الخادم المحلي وقاعدة بيانات Supabase/PostgreSQL السحابية. Integrity Audit
scripts/restore-from-supabase.mjs Scripts أداة التعافي من الكوارث (Disaster Recovery)؛ استعادة فورية لملف قاعدة البيانات من السحابة في ثوانٍ عند حدوث طارئ. Disaster Recovery
render.yaml & docker-compose.yml Root ملفات تشغيل الحاويات، متغيرات البيئة الآمنة، واستراتيجية النشر السحابي التلقائي. Cloud Infrastructure
