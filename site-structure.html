🌐 بوابة الزوار والتوثيق

الموقع التعريفي وتسجيل الدخول

الواجهة الخارجية المفتوحة للجمهور قبل تسجيل الدخول، تهدف للتعريف بالمنصة وجذب الأفراد والمنظمات.

🏠 الصفحة الرئيسية (Root) مفتوح /
البوابة الأساسية لنظام التوجيه الديناميكي المعتمد على حالة الجلسة.
✨ صفحة الهبوط والتعريف مفتوح /landing
تعرض الهوية البصرية وخيارات التسجيل الفوري.
🔑 تسجيل الدخول مفتوح /auth/login
تسجيل دخول موحد للأفراد والمنظمات مع التحقق الصارم من الصلاحية.
📝 إنشاء حساب جديد مفتوح /auth/register
تجميع البيانات الأساسية وإنشاء الهوية الرقمية في قاعدة البيانات.
👤 بوابة المستخدم الفرد

بيئة التفاعل الاجتماعي والتعلم (/app)

المساحة المخصصة للأفراد للتفاعل في التغذية الإخبارية، حجز الأنشطة، الالتحاق بالدورات، ومراسلة الأقران.

📊 لوحة التحكم الرئيسية تسجيل مطلوب /app
نظرة شاملة ومحدثة على كل ما يهم المستخدم في مكان واحد.
📰 تغذية سرد التفاعلية تسجيل مطلوب /app/feed
شريان التواصل الحي: نشر الأفكار والتفاعل مع منشورات الأفراد والمؤسسات.
📅 الأنشطة والفعاليات تسجيل مطلوب /app/activities
محرك استكشاف الورش والفعاليات الحضورية والافتراضية.
🎓 الدورات التدريبية تسجيل مطلوب /app/courses
بوابة التدريب المهني والمهاري بالتعاون مع المنظمات المعتمدة.
👥 المجموعات والمجتمعات تسجيل مطلوب /app/groups
مجتمعات صغيرة مغلقة أو عامة تجمع أصحاب الاهتمامات المشتركة.
💬 المحادثات الفورية تسجيل مطلوب /app/messages
تواصل فوري سلس بين المستخدمين والمؤسسات المشاركة.
👤 الملف الشخصي تسجيل مطلوب /app/profile
السجل الرقمي المهني والمجتمعي لكل عضو في المنصة.
🏢 بوابة المنظمات والشركاء

إدارة الأنشطة والتدريب المؤسسي (/org)

لوحة تحكم احترافية للمنظمات لنشر الفعاليات، تدشين الدورات، متابعة الحضور، وتوسيع القاعدة الجماهيرية.

📈 لوحة القيادة المؤسسية خاص بالمنظمات /org
متابعة دقيقة للأداء التشغيلي والمجتمعي للمنظمة في الوقت الفعلي.
🎪 إدارة وتنظيم الفعاليات خاص بالمنظمات /org/activities
إشراف شامل على المقاعد، قوائم الانتظار، وبيانات المسجلين.
📚 إدارة الدورات والبرامج خاص بالمنظمات /org/courses
استوديو تدريب متكامل لنشر المحتوى التعليمي للمجتمع.
👥 إدارة طاقم المنظمة خاص بالمنظمات /org/members
توزيع الأدوار الإدارية والتدريبية لطاقم المؤسسة.
📊 التحليلات والتقارير خاص بالمنظمات /org/analytics
تقارير رقمية دقيقة تدعم اتخاذ القرارات الاستراتيجية للمنظمة.
🛡️ بوابة الرقابة والإدارة العليا

نظام بترا للتحكم المركزي (Petra Central Control)

محطة الإشراف الأمني والرقابي الشاملة للمنصة، تدعم التدخل الفوري، اعتماد المؤسسات، ومراقبة موارد النظام.

⚡ بوابة بترا المركزية (Gate 9921) سري وخاص /system-control-gate-9921
لوحة القيادة المباشرة لمسؤولي المنصة، تدير محرك Speed-Server والبيانات الحية.
🚨 إدارة البلاغات والمحتوى إشراف /admin/reports
مراجعة البلاغات المعلقة وحذف المحتوى غير المتوافق مع المعايير.
🏅 توثيق المنظمات الرسمية إشراف /admin/organizations
بناء الثقة عبر التحقق الصارم من هوية كل جهة تعلن أنشطة.
📜 سجلات التدقيق (Audit Logs) إشراف /admin/logs
توثيق كامل للأنشطة الحساسة لضمان الشفافية والأمان السيبراني.
💾 النسخ الاحتياطي ومطابقة البيانات (Supabase Sync) إشراف وأمان /api/backup/status
مزامنة البيانات مرتين يومياً (03:00 و 15:00 UTC) مع فحص تلقائي لتطابق السجلات واستعادة الكوارث.
الهيكل التقني للمشروع والملفات (Monorepo Codebase Layout)

تم بناء المنظومة وفق معمارية المستودع الموحد (Monorepo) بإدارة حزم pnpm workspaces مع فصل تام بين طبقة واجهات المستخدم، خادم الواجهات البرمجية، والمكتبات المشتركة:

💻 تطبيق الواجهات الأمامية (Frontend Web)
apps/web/

تطبيق ويب أحادي الصفحة (SPA) مبني بواسطة React 18 + Vite + TypeScript، مع تنسيقات Tailwind CSS ومكتبات Radix / Shadcn UI، ونظام توجيه خفيف وسريع عبر wouter.

⚙️ خادم الخدمات الخلفية (Backend API)
apps/api/

خادم سريع وعالي الكفاءة مبني بـ Node.js + Express مع محرك الذاكرة الفائق وسجل WAL، توثيق JWT آمن، ونقاط تحكم بترا المركزية.

📄 توثيق الواجهات البرمجية (OpenAPI Spec)
docs/openapi.yaml

مواصفات Swagger / OpenAPI الرسمية لتوثيق جميع مسارات الواجهات البرمجية والنماذج البيانية لمنصة سرد رقمي.

🗄️ قواعد البيانات والبيانات المستدامة
database/ [sard_production.sqlite, schema.sql]

19 جدولاً ومخطط بيانات متكامل يغطي المستخدمين، المنظمات، المنشورات، الأنشطة، والدورات، مع دعم التخزين فائق السرعة في الذاكرة بنمط WAL ومزامنة سحابية مستمرة.

🛡️ محرك النسخ الاحتياطي واستعادة الكوارث
scripts/ [sync-and-verify, restore, scheduler]

محرك أتمتة غير متزامن يقوم بمزامنة كاملة مرتين يومياً (03:00 و 15:00 UTC) مع Supabase، يشمل لقطة ثنائية و 19 جدولاً علائقياً، مع فحص تلقائي لتكافؤ السجلات (Auto-Check Parity) واستعادة طارئة في ثوانٍ.

معمارية الأداء الفائق والنسخ الاحتياطي التلقائي (Render ➔ Supabase Architecture)

تعتمد منظومة «سرد رقمي» على بنية سحابية هجينة متطورة تضمن أعلى سرعة استجابة للمستخدمين مع أقصى درجات الأمان واستدامة البيانات:

⚡ الطبقة الأساسية (Primary Production)

خادم وقاعدة بيانات Render

تتم جميع عمليات القراءة والكتابة اليومية للمستخدمين على خادم Render فائق السرعة عبر محرك الذاكرة ومزامنة WAL الموضعية، مع استجابة فائقة السرعة دون أي تأخير.

  • 🟢 سرعة استجابة خيالية: زمن استعلام يقل عن 1 مللي ثانية (< 1ms).
  • 🟢 عدم حجب الطلبات: طلبات المستخدمين لا تنتظر Supabase أو أي اتصال خارجي.
  • 🟢 استمرارية التخزين: حفظ مستمر في قاعدة Render PostgreSQL (sard_production).
🛡️ طبقة الأمان والنسخ (Backup & Redundancy)

النسخ الاحتياطي السحابي في Supabase

محرك مزامنة غير متزامن يعمل مرتين يومياً كل 12 ساعة (03:00 و 15:00 UTC) ينقل البيانات بشكل متدفق مع فحص تلقائي وفوري لتطابق كل جدول وسجل.

  • 🔵 جدولة آلية 2x يومياً: تعمل تلقائياً دون تدخل بشري في أوقات الهدوء (03:00 و 15:00 UTC).
  • 🔵 ازدواجية الحفظ الكامل: حفظ لقطة ثنائية نقية (sard_cloud_store) + 19 جدولاً علائقياً.
  • 🔵 التحقق الآلي من البيانات: فحص ومقارنة عدد الصفوف وأحدث التواريخ لكل جدول.
  • 🔵 سجل تدقيق دائم: توثيق كل عملية في جدول backup_audit_logs.

أدوات التشغيل وأوامر التحكم بالنسخ الاحتياطي (CLI & API Operations)

الأمر البرمجي النوع الوظيفة والهدف الصلاحية
pnpm run backup:sync CLI Script تنفيذ فوري لمزامنة اللقطة و 19 جدولاً إلى Supabase مع فحص التطابق وطباعة التقرير. Server / Cron
pnpm run backup:check CLI Script فحص تكافؤ السجلات وتطابق التواريخ بين Render و Supabase فقط دون تعديل (Read-only). Audit / DevOps
pnpm run backup:restore -- --force CLI Script استعادة النظام وقواعد البيانات بالكامل من Supabase إلى Render في ثوانٍ عند حدوث طارئ. Disaster Recovery
pnpm run backup:scheduler Daemon تشغيل مجدول النسخ الاحتياطي المزدوج المستقل (03:00 و 15:00 UTC) كخدمة خلفية. Cron Worker
GET /api/backup/status REST API استعلام فوري عن حالة النسخ الاحتياطي، موعد الدورة القادمة، وسجل التدقيق الأخير. Public / Status
POST /api/petra/backup/trigger REST API إطلاق عملية نسخ احتياطي وفحص فوري عبر لوحة بترا أو خطافات Webhooks المشفرة. Admin / Petra
