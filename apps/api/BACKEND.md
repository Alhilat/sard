# توثيق خادم المنصة (Backend Documentation — Sard Raqami)

## 1. التقنيات الأساسية (Tech Stack)

| الطبقة | التقنية المستخدمة | الوصف |
| :--- | :--- | :--- |
| **بيئة التشغيل (Runtime)** | Node.js 22 (Native ESM) | تشغيل نقي ومباشر بدون transpilation |
| **إطار العمل (Framework)** | Express.js 5 | خفيف، سريع، ومستقر |
| **محرك البيانات الأساسي** | SQLite 3 (WAL Mode عبر `node:sqlite`) | قراءة وكتابة متزامنة مع استقرار عالي وأداء محلي سريع |
| **الاستدامة السحابية** | PostgreSQL / Supabase | مزامنة تلقائية واسترداد الكوارث (Disaster Recovery) |
| **التوثيق والحماية** | JWT (JSON Web Tokens) + bcryptjs | تشفير وأمان فوري للجلسات والصلاحيات |

## 2. الهيكلية المعمارية النظيفة (Clean Layered Architecture)

## 3. الأداء والسرعة (Performance Metrics)

- **زمن الاستجابة للطلبات (Latency)**: أقل من `0.5 ms` لجميع نقاط النهاية المحلية.
- **استهلاك الذاكرة**: خفيف جداً (~35MB RAM).
- **الاسترداد التلقائي للكوارث (Disaster Recovery)**: في حال حذف قاعدة البيانات المحلية، يقوم الخادم تلقائياً باسترجاع كافة البيانات والجداول من سحابة Supabase / PostgreSQL عند أول بدء تشغيل.
