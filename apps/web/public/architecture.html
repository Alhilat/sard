Frontend UI Core Page
💬
apps/web/src/pages/app/Feed.tsx
💡 التشبيه: مثل "الساحة العامة أو تويتر سرد"

صفحة السرد العام الكبرى لجميع رواد المنصة. تحتوي على صندوق كتابة السردات بالأيقونة فقط، دعم استطلاعات الرأي، تبويبات (لك، المتابعون، الرائجة)، والتحديث اللحظي للمنشورات مع التوقيت النسبي الحقيقي.

  • زر النشر بأيقونة السرد فقط (36x36px) مضاد للاقتطاع على الهواتف.
  • زر مشاركة حقيقي يفتح Web Share API الأصلي للهاتف.
  • يرتبط بـ: postsService.ts و ShareModal.tsx.
Frontend UI Layout
📱
apps/web/src/layouts/AppLayout.tsx
💡 التشبيه: مثل "هيكل المبنى الرئيسي والأبواب"

الإطار العام لجميع صفحات المستخدمين المسجلين. يحتوي على القائمة الجانبية للشاشات الكبيرة، وشريط التنقل السفلي المريح لشاشات الهواتف الذكية، وشريط الرأس العلوي مع عداد الإشعارات والبحث.

  • يضمن عدم وجود أي انزلاق أو تمرير أفقي على شاشات الهواتف.
  • استماع دوري لعدد الإشعارات غير المقروءة وتشغيل نغمة التنبيه.
Frontend UI Live Chat
🗣️
apps/web/src/components/activities/ActivityGroupChat.tsx
💡 التشبيه: مثل "قاعة المحاضرات الحية المكتملة"

غرفة المحادثة اللحظية للفعاليات والأنشطة (ومثلها للدورات). تم تحويلها إلى شاشة كاملة (Full Screen 100dvh) لمنع التشتت، مع زر تحكم مصغر للمشرفين المنظمين لضبط صلاحيات الحديث والإعلانات المثبتة.

  • دعم وضع الصمت (Muted)، ووضع حديث المنظمين فقط، ووضع الجميع.
  • تحديث تلقائي كل ثانيتين للرسائل الحية.
Service Data Client
📡
apps/web/src/services/postsService.ts
💡 التشبيه: مثل "المندوب السريع بين الشاشة والخادم"

الخدمة البرمجية المسؤولة عن جلب المنشورات من الـ API، ونشر المنشورات الجديدة، وتسجيل الإعجابات بتحديث متفائل (Optimistic UI) لكي يشعر المستخدم باستجابة فورية حتى قبل رد الخادم.

  • تحتوي على واجهة Post مع توقيت النشر الفعلي createdAt.
  • استخراج الوسوم التلقائي (Hashtags) من محتوى المنشور.

  • يضمن ظهور توقيت حقيقي وموثوق لكل منشور ورد في التطبيق.
Backend Entry Point
🚀
apps/api/server.mjs
💡 التشبيه: مثل "مفتاح تشغيل المحرك الرئيسي"

المدخل النظيف المختزل للخادم (67 سطراً فقط). يقتصر دوره على تشغيل الخادم بالمنفذ المخصص، واستدعاء تهيئة قاعدة البيانات، وإيقاف التشغيل الآمن (Graceful Shutdown) لحفظ كافة العمليات العالقة في الذاكرة.

  • تم اختزاله من 3,265 سطراً إلى 67 سطراً نظيفاً.
  • يستمع للإشارات البرمجية SIGINT و SIGTERM للإغلاق النظيف.
Backend Express App
🏢
apps/api/app.mjs
💡 التشبيه: مثل "مكتب الاستقبال وإدارة المكاتب"

يجمع كافة وسائط الأمان (CORS, Express JSON limit 15MB)، ويقيس سرعة استجابة الخادم لكل طلب عبر metricsMiddleware، ويخدم ملفات الواجهة المجمعة تلقائياً في بيئة الإنتاج على Render.

  • توجيه مسارات /api إلى موزع المسارات المركزي.
  • توجيه كافة الروابط الأخرى لخدمة تطبيق React كـ SPA.
Routes
📝
apps/api/routes/posts.mjs
💡 التشبيه: مثل "مكتب تحرير ومراجعة المنشورات"

يعالج طلبات جلب المنشورات، النشر الجديد، الإعجابات، المشاركات، والتعليقات. يحسب التوقيت النسبي اللحظي ويرسل إشعاراً للمؤلف عند تفاعل أي شخص مع محتواه.

  • حساب التوقيت النسبي اللحظي formatRelativeTime(r.created_at).
  • التحقق من قائمة المستخدمين المحظورين في الذاكرة O(1).
Routes Admin Portal
🏛️
apps/api/routes/petra.mjs

بوابة بترا للإشراف والرقابة وحوكمة المنصة. توفر إحصائيات الأداء اللحظية، ومراقبة بلاغات المستخدمين، وإيقاف الحسابات المخالفة وتوثيق المنظمات المعتمدة.

  • محمية بوسيط petraAuthMiddleware الصارم.
  • مراقبة قياسات الخادم (متوسط زمن الاستجابة، استهلاك الذاكرة).
Database SQLite Engine
⚡
apps/api/db/index.mjs
💡 التشبيه: مثل "الخزنة السريعة في قلب البنك"

المحرك المركزي لقاعدة البيانات. يعتمد على ميزة node:sqlite الأصيلة المدمجة في Node.js 22 مع وضع WAL Mode، مما يمنح المنصة سرعة معالجة تفوق 10,000 عملية بالثانية بزمن يقل عن 1 ملي ثانية.

  • استدعاء الفحص الذاتي للكوارث والاسترداد عند الإقلاع.
  • تنسيق المزامنة السحابية غير المتزامنة مع PostgreSQL.
Database Cloud Persistence
☁️
apps/api/db/persistence.mjs
💡 التشبيه: مثل "شاحنة النسخ الاحتياطي التلقائية"

طبقة الاستدامة الهجينة. تعمل في الخلفية دون تعطيل المستخدم: بمجرد إضافة أو تعديل أي بيانات في SQLite، تقوم هذه الطبقة بنسخ التعديلات تلقائياً إلى PostgreSQL و Supabase.

  • عدم التأثير إطلاقاً على سرعة استجابة المستخدم (Non-blocking).
  • استراتيجية Upsert آمنة تمنع أي تكرار أو تعارض في البيانات.
Security Disaster Recovery
🛡️
apps/api/db/disaster-recovery.mjs
💡 التشبيه: مثل "نظام الإنعاش والطوارئ الآلي"

يفحص سلامة قاعدة البيانات المحلية عند بدء تشغيل الخادم. إذا انتهت فترة تجربة Render المجانية أو حُذفت البيانات المحلية بالخطأ، يقوم تلقائياً بسحب واستعادة كافة الجداول والحسابات من Supabase في ثوانٍ.

  • فحص نزاهة الجداول الـ 19 آلياً.
  • تسجيل كل محاولة استرداد في سجل التدقيق backup_audit_logs.
Scripts Automated Cron
⏰
scripts/backup-scheduler.mjs
💡 التشبيه: مثل "الحارس الذي يأخذ لقطة للمنظومة مرتين باليوم"

مجدول النسخ السحابي الدوري. يعمل مرتين يومياً (03:00 و 15:00 UTC) عبر Render Cron Job للتأكد من نقل أي بيانات جديدة بين Render Postgres وسحابة Supabase ومطابقة عدد السجلات بنسبة 100%.

  • يعيد المحاولة تلقائياً عند انقطاع الاتصال المؤقت.
  • يوفر تقارير تدقيق ومقارنة فورية بين السحابتين.
DevOps Infrastructure
🌐
render.yaml
💡 التشبيه: مثل "المخطط الهندسي لتشييد السحابة"

ملف البنية التحتية البرمجية (Infrastructure as Code) لخدمة Render. يحدد تلقائياً خدمة الويب الأساسية (Web Service)، ومهمة النسخ الاحتياطي الدوري (Cron Job)، وقاعدة بيانات PostgreSQL الملحقة.

  • يبني الواجهة والخادم بأمر واحد pnpm run build.
  • يربط المتغيرات البيئية الحساسة مثل JWT_SECRET و DATABASE_URL.
