📐 المعمارية الهندسية الهجينة (Hybrid Stack Architecture)

تعتمد منصة سرد رقمي نمط Local-First In-Memory with Hybrid Cloud Sync. القراءة والكتابة الفورية تتم في خادم Node 22 ومحرك SQLite WAL محلي بأقل من نصف ملي ثانية، بينما تتم المزامنة السحابية المزدوجة مع PostgreSQL و Supabase في الخلفية دون أي تعطيل للمستخدم.

🔄 مسارات التنفيذ الحقيقية (Step-by-Step Flow Simulator)

📝 مسار نشر سردة جديدة (Post Creation & WAL Commit Flow)

يوضح كيف تتم عملية النشر مع استخراج الوسوم التلقائي وحفظ البيانات في SQLite بزمن استجابة فوري:

1
واجهة المستخدم (Feed.tsx)
يقوم المستخدم بكتابة المنشور والضغط على زر السرد (أيقونة السرد فقط 36x36px). يتم فحص عدد الأحرف (≤ 280) وإرسال الطلب مع Bearer Token.
POST /api/posts { content: "فكرة تقنية جديدة #سرد_رقمي" }
2
وسيط الخادم ومصادقة التوكن (requireAuth Middleware)
يتحقق خادم Express من صحة توكن الـ JWT عبر jsonwebtoken.verify، ويفحص الذاكرة للتأكد من أن المستخدم ليس ضمن قائمة المحظورين O(1).
jwt.verify(token, JWT_SECRET) & checkBannedUsersCache(userId)
3
الكتابة في محرك SQLite WAL (Node Native DatabaseSync)
تنفيذ استعلام جاهز (Prepared Statement) لإدراج المنشور في جدول posts وتوليد التوقيت النسبي اللحظي العربي وحفظ الوسوم المستخرجة.
INSERT INTO posts (id, author_id, content, tags, created_at, timestamp_text) VALUES (...)
4
استجابة فورية للعميل وتحديث الواجهة المتفائل (< 0.5ms)
يرجع الخادم كائن المنشور المحدث بحالة HTTP 201، فتظهر السردة أعلى التغذية فوراً مع حساب التوقيت بدقة عبر formatArabicRelativeTime.
HTTP 201 Created { success: true, post: { ... } }
5
مزامنة سحابية غير معطلة (PostgreSQL Cloud Persistence)
في الخلفية وبدون تأخير العميل، يتم وضع المعاملة في رتل المزامنة السحابية لنقلها إلى Supabase PostgreSQL لضمان الديمومة الطويلة.
await syncTableToPostgres('posts', records)

💬 مسار محادثة الفعاليات وضبط الصلاحيات (Event Chat Moderation Flow)

يوضح كيفية تشغيل محادثة الفعالية بشاشة كاملة (100dvh) مع إدارة المشرفين لصلاحيات التحدث والإعلانات المثبتة:

1
فتح المحادثة (ActivityGroupChat.tsx)
عرض الغرفة بنمط 100dvh كامل الشاشة، وجلب آخر 50 رسالة مع إعدادات الغرفة الحالية عبر GET /api/activities/:id/chat/messages.
2
زر التحكم المصغر للمشرفين (Control Button)
إذا كان المستخدم هو منظم الفعالية أو مشرف معتمد، يظهر له زر ضبط مصغر يفتح نافذة إعدادات الغرفة (الصلاحيات، تثبيت إعلان، كتم).
3
تعديل الصلاحيات الفوري (PATCH Settings)
إرسال طلب التعديل إلى PATCH /api/activities/:id/chat/settings وتحديث جدول activity_chat_settings في SQLite فوراً.
PATCH /api/activities/:id/chat/settings { permission_mode: "organizer_only", pinned_announcement: "مرحباً بكم" }
